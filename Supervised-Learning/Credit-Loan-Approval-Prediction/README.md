# Credit Loan Approval Prediction

A machine learning project that predicts loan approval using classification algorithms and compares their performance to identify the best-performing model.

## Overview

This project covers the complete machine learning workflow, from data preprocessing and exploratory analysis to model training and evaluation.

## Workflow

- Data Cleaning & Missing Value Handling
- Exploratory Data Analysis (EDA)
- Feature Encoding & Scaling
- Correlation Heatmap
- Feature Engineering
- Model Training & Evaluation

## Models Compared

| Algorithm | Type |
|---|---|
| Logistic Regression | Linear Classification |
| K-Nearest Neighbors (KNN) | Distance-Based Classification |
| Naive Bayes | Probabilistic Classification |

## Best Performing Model

**Naive Bayes** — selected based on the evaluation results obtained on this dataset.

## Dataset

`loan_approval_data.csv`

**Language:** Python

**Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
