# 🏠 House Price Prediction using Linear Regression

## 📌 Project Overview

This project predicts house prices using **Linear Regression**, a supervised machine learning algorithm.

The model learns the relationship between different house features and the sale price of the house.

This is my first machine learning project, created to understand the complete workflow of a regression problem.

---

## 🎯 Objective

The main objective of this project is to:

- Understand a house price dataset
- Clean and prepare the data
- Perform Exploratory Data Analysis (EDA)
- Select useful features
- Train a Linear Regression model
- Make house price predictions
- Evaluate the model performance
- Predict the price of a new house

---

## 📊 Dataset

The dataset contains information about houses and their sale prices.

### Features Used

- `TotalBsmtSF` – Total basement area
- `YearBuilt` – Year the house was built
- `YearRemodAdd` – Year the house was remodeled
- `LotArea` – Lot area of the house

### Target

- `SalePrice` – Sale price of the house

## 📈 Model Performance

The model was evaluated using:

- **MAE (Mean Absolute Error)**
- **MSE (Mean Squared Error)**
- **RMSE (Root Mean Squared Error)**
- **R² Score**

### Results

- MAE: `37880.07`
- MSE: `3305725582.19`
- RMSE: `57495.44`
- R² Score: `0.569`

The R² score means that the model explains approximately **56.9% of the variation in house prices** using the selected features.
